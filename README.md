# AC-Sharing-Log

A comprehensive Python application for managing and tracking AC sharing logs with full CRUD (Create, Read, Update, Delete) functionality.

## Features

- ✅ **Create** - Add new sharing log entries
- 🔍 **Read & Search** - Query and retrieve sharing log data with advanced search capabilities
- ✏️ **Update** - Modify existing log entries
- 🗑️ **Delete** - Remove log entries
- 💾 **Data Management** - Robust data handling and storage

## Project Structure

```
AC-Sharing-Log/
├── main.py                    # Main entry point
├── create_module.py           # Create operations
├── readandsearch_module.py    # Read and search operations
├── update_module.py           # Update operations
├── delete_module.py           # Delete operations
└── data_module.py             # Data management utilities
```

## Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/AC-Sharing-Log.git
cd AC-Sharing-Log
```

2. Ensure you have Python 3.7+ installed:
```bash
python --version
```

## Usage

Run the application:
```bash
python main.py
```

The application provides an interactive interface for managing AC sharing logs with options to create, read, update, and delete entries.

## Requirements

- Python 3.7+
